# Event image assets

Replace these files with club-owned images using the exact names below. Keep the extension truthful to the file format.

- `club-logo.png` — transparent logo for the projector promo loop.
- `promo-opportunities.jpg` — Opportunities promo image.
- `promo-3v.jpg` — 3V promo image.

Social and event QR codes are generated from the URLs in Host Setup; do not upload QR screenshots. Replacing static images requires a new deployment. Use optimized, high-resolution images and avoid uploading images you do not have permission to publish.
